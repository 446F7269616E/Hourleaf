# 界面样式与排版

Hourleaf 使用现有的浅灰背景、白色卡片、居中胶囊导航和五套主题色。界面精修集中在阅读层级、间距、控件尺寸和窄屏适配。时间摘要仍是仪表盘和工具栏的视觉重点，计划仍使用自适应卡片网格，设置仍使用折叠分组和字段卡片。

## 开发目录

| 模块                                         | 职责                                                 |
| -------------------------------------------- | ---------------------------------------------------- |
| `src/styles/tokens.css`                      | 明暗配色、字体、共享字号、控件高度、面板内边距和阴影 |
| `src/styles/base.css`                        | 标题、基础控件、焦点滚动留白、长文本、弹窗与公共状态 |
| `src/styles/navigation.css`                  | 居中导航、页面选中状态、帮助弹窗和窄屏导航           |
| `src/styles/dashboard.css`                   | 统计卡片、日期范围、趋势图与网站分布                 |
| `src/ui/viewport-scroll-panel.ts`            | 根据可见空间维护桌面侧栏高度，清理重绘及视口监听     |
| `src/ui/clock-input.ts`                      | 强制 24 小时制 HH:mm 输入及跨午夜/全天提示           |
| `src/ui/configuration-directory.ts`          | 网站与白名单共用的左侧目录、数量摘要及选中样式       |
| `src/ui/configuration-controls.ts`           | 网站与白名单共用的字段、开关、星期选择及日期摘要     |
| `src/styles/options.css`                     | 网站目录、独立配置卡片、时间段和配置弹窗             |
| `src/styles/home.css`                        | 折叠设置分组、说明列与控件列、字段卡片               |
| `src/styles/plan.css`                        | 计划卡片、按钮区、思维导图与事项编辑                 |
| `src/styles/block.css`                       | 网站模块、过滤选项与适用时间段                       |
| `src/styles/popup.css`、`src/styles/end.css` | 工具栏摘要与暂停页的紧凑排版                         |

共享尺寸先修改 token，再由组件引用。页面样式只负责自身的信息密度和响应式，不修改业务消息、权限、存储和计时行为。

## 视觉基线

浅色基础色为：画布 `#f6f7fb`、内容面 `#ffffff`、正文 `#202333`、辅助文字 `#676b7d`、边框 `#e4e6ee`、森林绿 `#00824c`。现有主题色、深色模式、字体栈和圆角体系继续使用。

字体沿用 Inter / 系统无衬线字体，中文沿用 PingFang SC / Hiragino Sans GB / Microsoft YaHei。正文保持 14px；桌面页面标题为 30px，窄屏最低 26px；分区标题为 18px，计划事项标题为 15px，模块标题为 16px，主要辅助说明为 12px。紧凑标签和图表坐标按各自空间使用较小字号。时间与数量沿用等宽数字。

页面内容左对齐，暂停页主要操作居中。卡片内边距默认 20px，640px 以下为 16px；页标题下方留白默认 32px，窄屏为 24px。常规按钮和输入框高 42px，紧凑操作高 40px；粗指针设备通过相同 token 提升至 44px。强调按钮保留主题填充色，辅助操作保留现有浅色或边框样式，阴影适度减轻。

```text
           [ 品牌   仪表盘 / 计划 / 配置 / 屏蔽 / 设置   帮助 ]

页面标题                                           范围 / 视图

[ 主要统计 ] [ 辅助统计 ] [ 辅助统计 ] [ 辅助统计 ]
[ 趋势图                         ] [ 网站分布           ]
```

本次方向采用用户确认的原风格精修方案，保留现有视觉身份，通过字段关系、数字对齐和卡片内容层级改善使用效率。

## 页面约束

- 仪表盘保留分开的统计卡片；卡片按标签、数字、说明三行布局，数字居中对齐并允许长值换行。日期范围与统计区间隔 24px，统计卡片最小高 160px。
- 配置页左侧统一放置“网站”和“标签页组白名单”两个同级目录模块，各自显示配置数量；右侧只展示当前选中的网站或白名单配置。目录共用 `src/ui/configuration-directory.ts`，统一名称、摘要、选中高亮、键盘入口及空状态；切换类型保留各自上次选择，切换项目保留侧栏滚动位置。删除选中白名单后选中剩余首项，删空后显示对应空状态；网站为空时白名单仍独立可用。桌面侧栏整体吸附，目录网格使用 `max-content` 行高禁止内容压缩；侧栏按实际可见空间设定独立高度、仅自身纵向滚动并阻断滚动链，滚动左侧不带动右侧详情。高度更新合并在动画帧内并以吸附顶部为增长边界，组件重绘清理旧监听。860px 以下取消独立高度和内部滚动，在详情上方按原顺序堆叠两个目录。
- 配置页白名单沿用普通时间段的卡片标题栏、浅灰规则行、状态点、开关和图标按钮；新增/编辑弹窗统一使用 `.input`、`.field`、`.day-picker` 与起止时间布局。网站与白名单的字段、开关及星期选择由 `src/ui/configuration-controls.ts` 复用。白名单区块底部不放通用功能、优先级或生命周期长说明，只保留精简空状态和对应规则的绑定失效标记；跨午夜及全天提示仅在表单命中该情况时显示。同名组使用用户可读的顺序区分，不显示浏览器内部组 ID。
- 配置页左侧目录列宽 240px，与编辑区间隔 24px；网站详情按身份、限制模式、时间段、访问前确认排列。限制模式采用 12×16px 内边距、14px 标题、紧凑选择框，说明放在标题旁的宽列，避免挤在下拉框下面增高。访问前确认位于详情底部，自定义提示语开关开启时才显示输入区；关闭保留文字但确认页不显示。860px 以下改为单栏，目录以自适应网格排列，限制模式和提示字段同步堆叠。时间段说明允许换行，开关与编辑操作保持一组。
- 设置页按“运行与保护 / 界面与显示 / 计划访问 / 访问确认与解锁 / 暂停与结束页面 / 数据管理”分为六个独立折叠卡片；类别之间留出 16px，编辑后保留展开状态。宽屏控件列为 220–320px，与说明列间隔 24px；主要说明限制阅读宽度，字段卡片内边距 16px。700px 以下使用单栏，主题选项与其他控件统一左对齐。
- 计划固定使用独立计时，设置页不提供与普通额度耦合的旧切换项；普通暂停页的关闭按钮明确标注只关闭组外相关页，保留组内暂停页时提供关闭数量反馈。
- 计划页保持现有自适应卡片网格；同一行的列表卡片使用弹性内容列，使操作位于底部。长标题完整换行，链接保留省略行为；按钮组允许换行。思维导图继续使用原有节点测量与交互。
- 屏蔽页模块标题、过滤选项和时间段保持原有分组结构，优化说明文字和分区间距。
- 工具栏维持 380px 宽、600px 高上限及两张摘要卡片；主要时间字号为 22px，多组为 16px，长时间值可换行。暂停页保留三分区、时长圆环、分组条及菱形时钟标记，主要优化说明文字、分页与按钮间距。

所有时钟、时间段及计划时间戳统一显示 24 小时制，午夜为 `00:00`。时间输入使用共享 HH:mm 文本控件，以保证中文、英文和系统 12 小时偏好下的一致性；支持输入 `0900` 自动转为 `09:00`，浏览器表单校验拒绝无效小时/分钟。全天与跨午夜提示只对合法起止时间显示。时长单位仍按秒、分钟和小时展示。

## 交互细节与验收

根据 [Web Interface Guidelines](https://raw.githubusercontent.com/vercel-labs/web-interface-guidelines/main/command.md)，公共控件保留可见焦点；星期和规则选择的隐藏输入框在其 label 上显示焦点；弹窗采用独立滚动边界；公共加载动画响应减少动态效果设置。吸附导航下的聚焦控件留出滚动空间，长文本使用 CSS 换行处理。

按用户要求，仅执行 TypeScript 编译、CSS 编译、三浏览器正式构建与本机 Debug 构建。单元测试、E2E、浏览器截图和自动交互验收不在本次范围。人工检查应覆盖五个主页面、弹窗、暂停页、中英文、五套主题、深色模式、窄屏、200% 缩放、长标题及键盘操作。
