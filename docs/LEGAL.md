## 数据披露

“不收集数据”指扩展不将用户数据上传给开发者或第三方，不代表不在设备上读取、处理或保存数据。隐私政策应与存储模型、权限和实际执行行为一致。新增字段、备份范围、网络能力或权限时，更新对应章节及商店披露。

浏览器访问网站、用户主动打开外链、通过 GitHub 提交内容及商店分发更新，应与扩展自动上传数据区分。不得把静态导入检查表述为完整安全审计或第三方文件安全保证。

## 商店条款依据

- [Chrome Web Store 用户数据政策问答](https://developer.chrome.com/docs/webstore/program-policies/user-data-faq)及 [Limited Use](https://developer.chrome.com/docs/webstore/program-policies/limited-use)：披露数据用途并保持页面、隐私政策和实际行为一致。隐私政策包含 Limited Use 声明。
- [Mozilla Add-on Policies](https://extensionworkshop.com/documentation/publish/add-on-policies/)：说明实际功能、数据传输与用户可控行为；审核材料应披露全部能力。
- [Apple App Review Guidelines 5.1.1](https://developer.apple.com/app-store/review/guidelines/#privacy)：产品内及商店元数据提供隐私链接，说明数据用途、保留及删除。
- [Apple App Privacy Details](https://developer.apple.com/app-store/app-privacy-details/)：仅在设备处理且不传出的数据不属于该隐私标签定义的收集。原生容器及第三方组件也须纳入核对范围。

商店商品介绍以网站专注、计划和统计为重点；模块说明及下载独立发布。权限说明、用户脚本披露和审核说明仍须如实覆盖导入能力，不得因页面分离而遗漏。
