# Hourleaf 产品介绍

用于商店产品主介绍与 GitHub 项目介绍。权限、数据和审核字段分别见各平台提交说明。

## 简体中文

名称：Hourleaf

简短介绍：按自己的规则管理网站使用时间，安排专注计划，查看本地用时统计。

App Store 副标题：网站时间管理与专注计划

完整介绍：

Hourleaf 帮助你安排网站使用时间，把浏览节奏留在自己手中。

- 网站规则：为网站设置可用时段、使用额度和等待时间，按需要选择宽容、心流或严格模式。
- 专注计划：整理访问清单，设置独立计划时长和到期行为。
- 用时统计：查看每天、每周和各网站的使用情况，了解时间分配。
- 标签页组：在支持的浏览器中，为指定组设置白名单时间。
- 个性设置：切换浅色或深色外观，选择中文、英文或跟随系统，导出与恢复本地配置。

Hourleaf 无需注册账户。规则、计划和统计保存在当前设备，不上传至开发者服务器，不提供云同步，不含广告或遥测。网站权限由你按需授权。

部分能力取决于浏览器支持。Safari 不提供标签页组白名单。

## English

Name: Hourleaf

Short description: Manage website time, organize focus plans, and view usage statistics stored on your device.

App Store subtitle: Website time and focus plans

Full description:

Hourleaf helps you set your own pace for browsing.

- Website rules: Set available hours, usage budgets, and waiting periods. Choose flexible, flow, or strict behavior.
- Focus plans: Organize a visit list with its own duration and end behavior.
- Usage insights: Review daily, weekly, and per-site time to understand how you spend it.
- Tab groups: Set whitelist hours for a chosen group in supported browsers.
- Preferences: Choose a light or dark appearance and Chinese, English, or the system language. Export and restore local settings.

No account is required. Rules, plans, and statistics stay on your device. Hourleaf has no developer server, cloud sync, ads, or telemetry. Website permissions are requested when you choose to add a site.

Availability depends on your browser. Safari does not support tab-group whitelists.
