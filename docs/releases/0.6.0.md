# Hourleaf 0.6.0

Hourleaf 0.6.0 将配置核心重构为按网站管理多个独立时间段，并统一了计划、结束页、本地模块和跨浏览器发布流程。

## 主要更新

- 配置页改为实时保存；网站限制模式独立展示，每个时间段独立启停；
- 配置页新增一键添加时间段，可预览并应用三餐、午间分割、前 12 小时、后 12 小时和晚间预设；自定义模式可命名并组合多个时间段、保存后复用；导入与导出配置移动到设置页“数据管理”，预设生成的时间段与命名自定义预设随配置备份往返；
- 工具栏快速预览当前网站的剩余时间，并可在图标显示剩余分钟；
- 新增网站访问前确认和独立等待时间；
- 计划事项拥有预定时长和宽容 / 心流 / 严格模式，列表与思维导图布局重新设计；
- 设置页按层级和可折叠分组整理，结束页可配置激励文本与分组解锁方式；
- 新增简体中文 / English 标准本地化资源；
- 本地模块导入增加来源、作者、格式和危险能力检查，并保持明确风险确认；
- Chromium、Firefox、Safari 使用同一领域契约生成独立候选包。

## 可选模块

- `hourleaf-module-bilibili-1.2.4.zip`：相关视频屏蔽覆盖播放结束推荐，并在生效时通过用户脚本关闭网站的自动连播（需 User Scripts API）；动态信息流屏蔽同步覆盖原生及 Bewly/Ave Mujica 动态悬停弹窗、动态页热搜榜、动态更新及消息提醒标识。模块名称改为 `Bilibili`，保留已有模块 ID、分组 ID 与开关偏好；正式版需重新导入新版文件。
- 小红书、X、YouTube、百度贴吧升级为 1.0.1，名称直接使用网站名称。
- `hourleaf-module-bilibili-1.2.1.zip`：修复 BewlyBewly 与 Ave Mujica 首页推荐屏蔽，支持开放 Shadow DOM、首页三种网格布局、晚挂载及分组启停；保留原生首页规则与 `/` 聚焦搜索。需要同时更新 Hourleaf 核心并重新导入模块；模块不会自动更新。

下载模块后请先阅读其中的 JSON、CSS 和用户脚本，再在“屏蔽”页面一次选择解压后的全部文件并核对权限。

## 平台说明

- Chromium：用户脚本通过 User Scripts API 运行，需要浏览器允许用户脚本；
- Firefox：用户脚本能力使用可选权限；
- Safari：商店候选不执行导入的用户脚本，JSON、域名策略和自包含 CSS 仍可使用。

浏览器 ZIP 是源码侧载 / 商店候选文件，正式商店安装仍需要各平台签名。所有 ZIP 的 SHA-256 随资产提供。

## 本地修复（2026-09-12）

- 访问前确认的详细设置按启用状态折叠，修复 Chromium 确认页无法打开网站的问题。
- 新增默认开启的计划全屏蔽选项，普通/计划屏蔽调整独立保存并自动切换。
- 工具栏使用透明圆角白底图标，改善深色主题下的辨识度并避免实心方块边缘。
