# Hourleaf 0.6.0 版本记录

本文保留 0.6.0 系列的功能记录（2026-10-14）；当前版本见 [1.0.0](./1.0.0.md)。尚未单独发布的变更保留在 [CHANGELOG 的 Unreleased](../../CHANGELOG.md#unreleased)，不据此推定已有同内容的商店版本。完整行为见 [功能说明](../FEATURES.md)。

## 网站配置与访问

- 网站按时间段管理，每段独立启停、星期、起止时间、行为、额度和使用分组；配置实时保存。
- 内置三餐下饭、两段分割、午前、午后、晚间、早起鸟、夜猫子预设，自定义组合可命名、保存和复用。
- 重叠时一直可用优先于一直禁用，再判限额；没有时间段或全部停用时无限使用，仍统计实际用时并保留屏蔽及定时。
- 访问确认与分组解锁共用策略，默认等待 30 秒后主动确认，也可立即确认、使用方程、微积分或密码。同网站当前可用时段内共享确认，可启用新标签逐次确认。
- 网站底部的提示语开关独立控制文案；所有时间输入及时间戳采用 24 小时制。
- 宽容、心流和严格模式分别处理每组结束；心流只能延长一次，选择 1–15 分钟或当前视频结束，普通延时默认不扣后续组。

## 标签页组白名单

- 配置页有与网站同级的白名单目录，可按星期与时间窗口绑定已有浏览器组。
- 窗口内组内已配置且仍授权的网站无限可用，不扣普通额度，跳过普通确认和分组暂停，实际用时仍统计。
- 内容屏蔽和显式域名阻断保留，计划截止时间不延长；窗口结束或移出组恢复原普通规则与余额。
- 组绑定仅本次会话有效；组销毁、浏览器重启、配置恢复后需要重新绑定，规则本身保留。
- 普通暂停页关闭操作只关闭相关组外标签，所有组内页面及归属不确定的候选保留；计划关闭按事项来源处理。

## 独立计划

- 事项包含 URL、标题、目标备注、预定时长、到期模式及可选的视频结束暂停；支持批量添加、排序、完成和恢复。
- 开始前授权并确认时长与目标，确认后才创建本次计时；计划固定独立，不写普通网站统计或消耗配置额度，设置页移除原独立计时切换项。
- 有效计划绑定到确认标签页和精确来源，同源翻页、刷新及路由沿用截止时间，其他标签不继承。
- 离开来源、关标签、重启或显式结束会销毁计时；到期后重新进入网站会清理旧通知并回到普通规则，清单与预定时长保留。
- 列表与思维导图均将完成事项放到底部折叠区；导图支持拖动、缩放、键盘和适配画布。
- 来源切换先结算旧计时段，并清理前一来源的视频结束监听；心流恢复重试不会重复增加时长。

## 屏蔽与模块

- 每个内容分组可选择对应网站已有时间段，只读取起止时刻作为每天屏蔽窗口；时段停用、星期和普通额度不影响屏蔽定时。
- 普通与计划偏好独立保存，计划默认使用已安装模块的计划屏蔽偏好，不自动安装或扩大权限。
- Bilibili 1.2.5 提供首页、动态、相关视频和评论过滤，以及搜索快捷键；评论覆盖动态视频卡片精选评论，动态联动提醒标识，相关视频覆盖片尾推荐并通过用户脚本关闭自动连播。
- 小红书、X、YouTube、百度贴吧当前模块版本为 1.0.1；五个模块的名称、说明与过滤组文案随中英文切换，稳定 ID 和偏好不变。
- 模块与扩展包分开，下载并审阅后在屏蔽页选择本地文件导入，不自动下载或更新。详细能力见 [模块目录](../../optional-modules/README.md)。

## 界面、统计与数据

- 五个页面共用居中导航；配置左侧网站与白名单目录独立滚动，窄屏恢复文档流。设置分为六个折叠类别。
- 支持简体中文、English、跟随系统、五套主题及系统明暗。工具栏预览今日用时、剩余额度和待办；图标显示剩余分钟，白名单及无限访问不显示普通额度倒计时。
- 仪表盘支持日/周/月/年；普通暂停页显示分组余额、24 小时柱状图和网站分布，计划暂停页保持目标与时长布局。
- 本地 JSON 备份包括规则、自定义预设、白名单时段、计划及兼容模块偏好，不含统计、运行授权、组绑定或模块源码；恢复需要重新绑定组，仅应用已安装同版本模块偏好。
- 关闭保护可选等待或密码；恢复默认和清空均需 120 秒及指定文字确认。恢复默认保留统计、计划清单与模块，清空删除全部业务数据。

## 平台与构建

Chromium、Firefox 和 Safari 各生成一个候选 ZIP，模块 ZIP 单独打包，并分别提供 SHA-256。Chromium 用户脚本需要用户开启浏览器能力，Firefox 使用可选权限与对应 API；Safari 构建拒绝脚本导入和执行。标签页组白名单需要组 API 与会话存储，Safari 不提供组放行。源码候选不代表商店已审核或签名。

本地自动验证范围为 TypeScript 编译与构建，交互和平台行为留给 [人工验收](../MANUAL_ACCEPTANCE.md)。远端 CI 保留格式、类型、Lint、单元覆盖、构建与打包流程。Debug 预置模块、测试站和固定权限仅供本地侧载，不上传发布。
