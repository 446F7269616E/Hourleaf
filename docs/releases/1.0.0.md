# Hourleaf 1.0.0

Release date: October 20, 2026.

## Changes

- Independent website windows with overnight schedules, custom presets, group allowances, and Lenient, Flow, and Strict modes.
- Multiple availability windows for tab-group whitelists. Group restoration matches local features and waits for rebinding when no unique match exists.
- Independent plan visits that retain deadlines across same-origin navigation and refresh, with list and mind-map views.
- Dashboard totals, daily averages, active days, peaks, hourly patterns, website shares, and plan completion.
- Consistent pause-page group progress, hourly usage, and actions; next-window information; fixes for tab restoration and closure scope.
- Local configuration backups, sidebar icons, themes, and English/Simplified Chinese. About links to privacy, the MIT License, and developer contact.
- Local processing for rules, plans, and statistics, without collecting or uploading user data.

## Downloads

- `hourleaf-1.0.0-chromium.zip`: Chromium extension resources for extraction and local loading. Store distribution requires review.
- `hourleaf-1.0.0-firefox.zip`: Firefox extension resources. Permanent installation requires AMO signing.
- `hourleaf-1.0.0-safari.zip`: Safari conversion resources requiring a container app and signing; not directly installable or ready for App Store upload.
- `hourleaf-1.0.0-review-source.zip`: Corresponding source, lockfile, and build instructions.
- `SHA256SUMS`: SHA-256 hashes for these files.

Browser behavior, signed installation, and store acceptance require manual checks. See [store submission materials](../STORE_SUBMISSION.md).
