# Hourleaf 1.0.0

发布日期：2026-10-19。

## 更新

- 网站规则按时间段独立管理，支持跨午夜、自定义预设、分组额度及宽容、心流、严格模式。
- 标签页组白名单支持多个可用时间段，恢复浏览器组时按本机特征匹配，无法唯一确认时需重新绑定。
- 计划使用独立访问计时，同源翻页和刷新保持截止时间，支持列表与思维导图。
- 仪表盘增加日均用时、活跃天数、峰值、小时分布、网站占比和计划完成概览。
- 暂停页统一分组进度、小时统计和继续操作，显示下次可用时间，修复跨标签页恢复及关闭范围。
- 设置支持本地配置备份、侧栏图标、主题和中英文；“关于”提供隐私政策、MIT 许可及联系入口。
- 全部规则、计划和统计在本机处理，不收集或上传用户数据。
