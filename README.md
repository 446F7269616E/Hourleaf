# Hourleaf

Hourleaf 是一款本地优先、开源、跨浏览器的网站专注扩展。你可以只授权自己想管理的网站，为同一网站设置多个独立时间段、使用分组和到期模式，并在本机查看日 / 周 / 月 / 年使用时间。

本文对应当前 `main` 功能，最近同步：2026-10-14。扩展版本为 `0.6.0`；未发布变更见 [更新日志](./CHANGELOG.md)。完整用法见 [功能说明](./docs/FEATURES.md)，开发入口见 [文档目录](./docs/README.md)。

## 五个页面

| 页面   | 用途                                                                 |
| ------ | -------------------------------------------------------------------- |
| 仪表盘 | 查看今日、本周、本月、本年的总用时、趋势和网站分布                   |
| 计划   | 添加、批量导入、排序、完成事项，切换列表或思维导图，开始独立限时访问 |
| 配置   | 管理网站、时间段、分组额度、访问提示语和标签页组白名单               |
| 屏蔽   | 导入本地模块，调整网站内容分组与每日屏蔽时间                         |
| 设置   | 管理运行与保护、界面、计划、确认与解锁、暂停页及本地数据             |

## 功能

- 添加任意 HTTP/HTTPS 网站并主动授权；普通网站按精确来源授权，Bilibili 使用已定义的 HTTPS 站点家族范围，不从其他输入自动扩大来源；
- 在配置页以时间段为主体；同一网站可拥有多个独立额度、一直可用或一直禁用的时间段，每个时间段独立启停并实时保存；
- 在配置页独立管理标签页组白名单，按星期和时段无限放行组内已授权网站，不扣普通额度，计划仍使用独立截止时间；组关闭或浏览器重启后显式重新绑定；
- 把一个时段额度平均分成多组，并用等待、数学题或本地密码开启下一组；
- 网站可选择宽容、心流或严格模式；心流每组只能继续一次，选择 1–15 分钟或当前视频结束；普通暂停页的关闭操作只影响相关组外标签，计划关闭操作按事项来源处理；
- 仅在页面可见、窗口聚焦且设备未空闲时计时；
- 可用时段优先于不可用时段，支持跨午夜，并可一键添加三餐、两段分割、午前、午后、晚间、早起鸟、夜猫子及可命名复用的自定义预设；
- 没有时间段或全部停用时，网站可无限使用并保留实际统计、内容屏蔽与屏蔽定时；有启用时段但当前未命中时仍不可用；
- 计划始终独立计时，不消耗普通用量或额度，也不把分钟数写入网站配置；有效期间同标签页内的同源翻页、刷新和路由切换保持原截止时间；
- 到期后重新进入网站会清理旧计时和通知，恢复普通网站规则；离开来源、关标签或浏览器重启会结束本次计划，清单和预定时长仍保留；
- 通过计划清单安排要访问的页面；每项有独立预定时长、到期模式和可选的视频结束暂停，支持自适应列表及可拖拽、缩放、适配画布的思维导图视图；
- 在仪表盘查看今天、本周、本月和本年的使用分布；
- 在浏览器快速访问入口查看当前网站今日已用时间和剩余时间；
- 所有设置、计划和聚合统计默认只保存在浏览器本地；
- 设置页可导出、恢复本地 JSON 配置，包含规则、自定义预设、白名单时段、计划清单和兼容版本的模块偏好，不包含统计、运行计时、组绑定或模块源码；
- 支持精确域名黑名单/白名单、元素隐藏与自包含 CSS；
- 从本地 `.json`、`.css`、`.user.js` 文件导入、启停或删除可选模块；
- 在独立“屏蔽”页面按网站启停模块及其推荐流、评论等可配置内容分组；
- 每个屏蔽选项可多选配置页中对应网站的已有时间段，只读取起止时间、按每天的黑名单范围生效，默认不限时间；
- Chromium / Firefox 用户脚本仅通过浏览器的隔离 User Scripts API 执行；
- 使用同一套界面和数据契约构建 Chromium、Firefox 与 Safari 版本；
- 界面支持五套主题色、系统明暗、简体中文、英文和跟随系统语言；五个仓库模块的名称、说明及分组文案也随语言切换。

标签页组白名单只在时间窗口内放行组内已配置且仍授权的网站，跳过普通额度、分组暂停与访问确认，记录实际用时。它保留内容过滤与显式域名阻断，不延长计划截止。Chromium 与具备组 API 和会话存储的 Firefox 支持此功能；Safari 或缺少接口时保留规则并显示不可用状态。

## 商店核心与本地模块

Hourleaf 商店包只提供通用、可解释的专注核心：计时、精确网站权限、域名策略、元素隐藏、CSS、模块导入器和平台允许的用户脚本隔离环境。商店包不内置 Bilibili 或其他网站的专用可执行模块。

GitHub 的 [Release 页面](https://github.com/446F7269616E/Hourleaf/releases/latest) 提供与扩展安装包分开的可选模块 ZIP，[可选模块目录](./optional-modules/) 保留可审查源码。Hourleaf 不会联网读取目录、检查模块更新或根据 URL 执行代码。用户需要先下载并阅读文件，再在“屏蔽”页面手动选择本地文件、核对网站范围并授权。Bilibili、小红书、X、YouTube 和百度贴吧专注模块按当前本地模块安全边界维护，但不会预装。

模块清单只接受精确 HTTP(S) 来源，并拒绝非空 DNR 规则；CSS 禁止远程 `@import`；用户脚本不会通过 `eval`、`Function`、script 标签或通用 scripting API 执行。普通与计划偏好独立保存，计划默认启用已安装模块的内容分组，仍受网站权限和分组定时约束，不自动安装模块或申请权限。

平台边界：

- Chromium：使用官方 [User Scripts API](https://developer.chrome.com/docs/extensions/reference/api/userScripts)，用户还需在扩展详情中允许用户脚本；
- Firefox：使用官方 [MV3 User Scripts API](https://developer.mozilla.org/docs/Mozilla/Add-ons/WebExtensions/API/userScripts) 和可选权限；
- Safari 候选：构建层禁止导入/执行用户脚本，只保留 JSON、域名策略与自包含 CSS；不提供标签页组放行。

商店候选不加载远程代码。正式商店分发需分别完成平台审核与签名；源码支持相应构建不代表已完成商店发布或人工验收。

每个平台只生成一个 `hourleaf-<version>-<browser>.zip`。GitHub ZIP 是源码/开发者侧载产物；Chrome、Firefox 与 Safari 的正式安装仍分别以 Chrome Web Store、AMO 签名和 App Store 签名版本为准。

## 从源码运行

需要 Node.js 22 或更高版本。

```bash
npm ci
npm run build
npm run package
```

构建目录：

- `dist/chromium`、`dist/firefox`、`dist/safari`：完整扩展；
- `dist/packages`：商店候选 ZIP 与 `SHA256SUMS`；
- `dist/modules`：与扩展包分离的可选模块 ZIP 与 `MODULE-SHA256SUMS`；
- `optional-modules/`：源码仓库中的可选本地模块，不进入商店构建产物。

本地联调可运行 `npm run build:debug`，默认生成仓库外的独立 Chromium 侧载目录，并预置当前可选模块及对应网站规则。该目录不得发布或上传；完整隔离约束见[本地 Debug 构建](./docs/LOCAL_DEBUG_BUILD.md)。

Chromium 可在 `chrome://extensions` 打开开发者模式后加载 `dist/chromium`。Firefox 可在 `about:debugging#/runtime/this-firefox` 临时载入 `dist/firefox/manifest.json`。

Safari 需要 macOS 和当前 Xcode：

```bash
xcrun safari-web-extension-packager dist/safari \
  --app-name Hourleaf \
  --bundle-identifier io.github.hourleaf.Hourleaf \
  --swift
```

真机、TestFlight 或 App Store 分发需要有效的 Apple Developer 身份与签名。

## 隐私与权限

Hourleaf 的必需权限用于本地存储、当前页预览、空闲状态判断、注册已授权网站的内容脚本，以及支持平台的标签页组查询。`http://*/*` 与 `https://*/*` 只声明为可选范围；普通网站申请精确来源，Bilibili 使用明确的站点家族范围，不会默认读取所有网站。

使用统计仅保存网站标识、本地日期、小时和聚合秒数，不保存普通浏览的完整 URL、网页正文、搜索词或账号信息。计划清单保存你主动添加的 URL、标题、目标备注、顺序、完成状态、预定时长与到期选项；活动计划及组绑定只保存在当前浏览器会话。本地模块文件保存在扩展本地存储中，删除模块后移除。详情见 [PRIVACY.md](./PRIVACY.md)、[本地模块规范](./docs/LOCAL_MODULES.md) 与 [威胁模型](./docs/THREAT_MODEL.md)。

## 暂停、心流与关闭保护

网站访问前与每组结束后共用暂停页，显示用量、剩余额度和可选激励语。默认等待 30 秒后主动确认，可改为立即确认、方程、微积分或密码；等待范围为 1–10800 秒。同网站在当前可用时段内共享确认，开启“新标签页重复确认”后逐标签确认。网站详情底部的提示语开关只控制文案。心流每组可延长一次，额外时间单独统计；是否扣减后续额度默认关闭。计划开始前确认时长和目标备注。

设置支持关闭插件前等待 1/3/5/10 分钟或输入独立密码；清空全部数据与恢复默认设置均需等待 2 分钟并输入指定确认文字。恢复默认会清除关闭密码。Debug 快捷测试与本地视频站用法见 [Debug 开发说明](docs/LOCAL_DEBUG_BUILD.md)，交互验收项见 [人工验收](docs/MANUAL_ACCEPTANCE.md)。

恢复默认保留统计、计划清单和已导入模块；清空全部数据将删除这些数据。恢复配置只恢复本机已安装且版本一致的模块偏好，不凭备份安装代码；组绑定和运行授权清理后需要重新建立。

暂停页用分段条展示分组：已用空心、剩余实心；今日统计提供 24 小时柱状图、今日总量及各网站用时，点击网站可切换小时分布。更新前的历史数据保留总量，缺失的小时明细不会推算补填。
